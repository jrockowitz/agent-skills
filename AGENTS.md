# Agent instructions

- Do not create Git worktrees. Work directly in the current repository or worktree.
- Let the owner review all changes before committing or pushing code, and all tickets or
  comments before saving or submitting, unless a skill or prompt permits skipping review.
- End commits made by an AI agent with `AI-assisted by {code agent name}`. Begin tickets
  and comments made by an AI agent with the same note.
- When cloning repositories hosted on `git.drupalcode.org`, use the SSH clone URL.
- Wrap Markdown prose at 80–100 characters when practical; keep lines at 100 characters
  or fewer.
